# Contributing

## Feedback and requests

Public Issues are the supported channel for bug reports, feature requests, and product feedback.
Before opening an Issue, search existing Issues and remove credentials, resource identifiers, and
customer data from any details you share.

## Code contributions

External code contributions are not accepted. External pull requests are not supported and will be
redirected to a public Issue or closed.

This repository is generated from a private source repository. Direct edits to files in this public
repository, including governance files, are overwritten by a later generated publication.

CODEOWNERS routes review notifications to the repository owner. It does not require the owner to
self-review or self-approve a release pull request. The owner merges generated release pull requests
after all required CI checks pass.

## Security reports

Do not open a public Issue for a suspected vulnerability. Follow the private reporting instructions
in [SECURITY.md](SECURITY.md).
