# DX-019: Paid continuous backup on non-production

[Catalog](../detectors.md) | [Access and sign-in](../permissions.md)

## Data and scope

An account-level ARM configuration check for continuous backup retention and a positively
inferred non-production environment. The shared environment classifier uses tags and names;
unknown environment is treated as production. Confirm the inference with the account owner.
The predicate requires no metrics or Log Analytics.

## Detection and severity

| Backup/environment evidence | Result |
|---|---|
| Continuous30Days or Continuous35Days on non-production | Medium |
| Continuous7Days on non-production | Not detected by the paid-storage rule |
| Continuous backup on production/unknown environment | Not detected |
| Periodic backup | Not detected |
| Missing backup mode | Unknown |
| Missing/unrecognized continuous tier on non-production | Unknown tier; abstain |

Recognized tier names are case-insensitive. This is a point-in-time configuration decision.
It reviews paid retention, not whether point-in-time restore itself should be disabled.

## Evidence and limits

For a positive finding, optional enrichment inventories logical containers through ARM and
requires one fresh, complete `DataUsageV2` snapshot from a reference region, with each expected
database/container present exactly once. It uses exact current recurring PITR storage prices
for every configured region, in one currency.

The estimate is logical decimal GB (`bytes / 1,000,000,000`) multiplied by the sum of
per-region recurring-storage rates. Do not sum time buckets or replicated regional metric
copies. Restore charges are separate. Missing, stale, duplicate or invalid storage/price
inputs omit the estimate; they do not erase the finding or become zero savings.

The estimate carries `azure_retail_price` provenance and is not mixed into customer-bill
savings totals. A genuine measured zero remains zero. Public list prices are not negotiated
customer rates. A historical implementation/threshold label is not fresh account acceptance.

## Remediation and references

No verified Agent Kit mapping is emitted (`agent_kit_rule` is null). Evaluate Continuous7Days
only if seven days of restore history meets the recovery policy: older restore points are
lost and restores remain separately chargeable. Do not recommend reverting continuous backup
to periodic. CODA does not alter retention or backup mode.
