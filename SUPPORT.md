# Support

CODA is provided with best-effort support through
[public GitHub Issues](https://github.com/AzureCosmosDB/coda/issues).

Open an Issue to report a product problem or request a feature. Include the CODA version, operating
system, the command you ran, and a redacted description of the result. Do not include credentials,
resource identifiers, customer data, or suspected vulnerability details.

Suspected vulnerabilities must be reported through the private channel described in
[SECURITY.md](SECURITY.md), not through a public Issue.
